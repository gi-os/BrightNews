Light RSS

Paste a feed address, point the phone at the code, done. No typing a URL on a Light Phone keyboard.

Enter an address to generate a code.

Scanning it

  1. Open Light RSS on the phone.
  2. Tap the list icon for Subscriptions, then +.
  3. Choose Scan QR code and allow the camera the first time.
  4. Frame this code. The feed is fetched and added on the spot.

A website address works too — the app looks for the RSS or Atom link on the page and subscribes to whatever it finds.

Getting the app

Signed APKs are on the releases page. Install once with adb install -r, or add https://github.com/gi-os/LightRSS to Obtainium for automatic updates. See INSTALL.md.

Everything here runs in your browser. The address you paste is never sent anywhere, and this page loads nothing from a third party. QR encoding by qrcode-generator (MIT).
